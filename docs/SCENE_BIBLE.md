# 常用校园场景规格表 (Scene Bible)

> **项目名称**：`ai_movies` - 校园青春系列  
> **设计原则**：严格的空间坐标系 + 真实中国普通公办高中建筑肌理 + 连贯的光影时序系统。拒绝欧美贵族学校风格与空旷奢华感，还原真实、拥挤、充满备考烟火气的青春场景。

---

## 一、 场景空间坐标与方位守恒定律 (Spatial Continuity)

在 AI 生图与视频拼接中，**空间轴线错乱是最大的跳戏源头**。本项目所有镜头严格遵循以下教室空间坐标：

```text
              【讲台 / 黑板 / 老师走动区】(前方)
  ┌────────────────────────────────────────────────────────┐
  │                                                        │
[门]                                                      [窗]
走│  [第一排: 班长林舟]     ...      [第一排: 晚晚新座位]  │
廊│                                                        │窗
过│          ...           ...              ...            │
道│                                                        │外
  │  【江野座位: 靠走道】  ────并排────  【陆晚晚座位: 靠窗台】│走
  │  (左侧: 183cm 男主)                (右侧: 162cm 女主)  │廊
  │                                                        │
  └────────────────────────────────────────────────────────┘
              【教室后黑板报 / 储物柜 / 拖把桶】(后方)
```

### 空间红线守则：
1. **右侧永远是窗户**：采光一律从**画面右侧向左侧**照射；
2. **同桌位置固定**：两人并排坐时，**江野在左（靠过道），陆晚晚在右（贴窗台）**，绝不可左右镜像反转；
3. **窗外递水动线**：外班男生必定出现在**右侧窗外探身**，江野从**左侧过道**走回，俯身越过课桌完成截胡；
4. **常驻道具位置**：桌角那个**银色不锈钢保温杯**永远摆在**陆晚晚右前方靠近窗台的位置**。

### 场景 1：高三普通教室 (Classroom - The Window Seat)

#### 1. 核心视觉要素
* **课桌**：浅黄原木色或浅绿斑驳木课桌，桌面布满水笔划痕、圆规刻印，堆着厚度达 40cm 的《五年高考三年模拟》、《金考卷》、真题红皮书与泛黄草稿纸。
* **墙体与设施**：白墙底部涂着经典的湖水绿油漆防污墙裙；头顶悬挂白色双管日光灯与微摇晃的三叶铁吊扇；墙边挂有白色塑料壁扇。
* **窗户与窗帘**：老式铝合金或白色推拉窗，挂着洗得微褪色的蓝白拼色布窗帘；窗外是茂密遮阳的法国梧桐或香樟树。

#### 2. 即梦 / Midjourney 标准 Prompt

##### 【白天燥热自习课·空镜】
```markdown
16:9横屏，中国青春电影空镜头，写实生活质感。
盛夏午后的中国普通公办高三教室窗边位置，微风轻轻掀起蓝白棉布窗帘，窗外是强烈的夏日白光和茂密翠绿的香樟树叶。
木质双人课桌上凌乱堆积着如小山般的五年高考三年模拟真题卷、厚重教辅教材、泛黄草稿纸、黑色网格笔筒和一个立式银色不锈钢保温杯（黑塑料杯盖）。
头顶悬挂老式三叶风扇在微弱转动，日光穿透玻璃在桌面投下明亮而斑驳的丁达尔光束与漂浮微尘。安静、燥热但怀旧的高考备战氛围，35mm电影胶片质感，真实写实摄影，无人物，阿莱摄影机拍摄，8k分辨率。
```

##### 【傍晚放学·温柔晚霞空镜】
```markdown
16:9横屏，中国青春电影空镜头，放学黄昏氛围。
空无一人的高三教室靠窗课桌，下午五点半的柔和自然斜阳从右侧大玻璃窗外平缓照进，光线温暖柔和、通透自然不刺眼，绝不过饱和无泛黄浓烈滤镜。
课桌上的五三试卷边缘和银色保温杯被镀上一层极细的微暖淡金色轮廓光，蓝白窗帘静止，窗外天边泛着淡紫粉橙色的自然薄霞，空气澄净怀旧。35mm电影胶片，真实质感，无人物，8k。
```

### 场景 2：教学楼走廊与窗外连廊 (Corridor & Window Outside)

#### 1. 核心视觉要素
* **地面**：浅灰色水磨石地板，带铜条拼接缝，反光自然。
* **栏杆与墙壁**：齐胸高的红砖水泥护栏或白色瓷砖围栏；走廊墙壁贴着“严谨 求实 拼搏 进取”红色标语或年级月考红榜光荣榜。
* **功能作用**：外班男生探身递水、课间两人并排倚着栏杆吹风、江野拎着水杯从水房打水归来的动线发生地。

#### 2. 标准 Prompt
```markdown
16:9横屏，中国青春电影剧照，学校教学楼外廊。
微风拂过的高中走廊，浅灰色水磨石地面，齐胸高的白瓷砖护栏。栏杆外是盛夏阳光下繁茂的绿色法国梧桐树冠与蝉鸣。
从走廊往教室窗内看，窗台干净，玻璃半开。走廊尽头是拐角的开水房，日光在走廊投下拉长的柱子阴影，充满生活气息的下课课间氛围，35mm胶片，真实摄影，8k。
```

### 场景 3：学校田径操场与看台 (Sports Ground & Bleachers)

#### 1. 核心视觉要素
* **跑道与草坪**：红白相间的塑胶跑道（地面有微热的空气波动），中间是绿草足球场，白石灰画线。
* **看台**：斑驳的水泥阶梯看台，后方有茂密的香樟树投下大片阴凉。
* **核心剧情承载**：体育课男生打篮球/测 800 米跑，女生在树荫看台抱膝看球、递矿泉水、挡飞来的篮球。

#### 2. 标准 Prompt

##### 【午后烈日·体育课看台】
```markdown
16:9横屏，中国青春电影剧照，高中红色塑胶跑道与水泥看台。
盛夏午后的烈日倾斜，热气在红色跑道上方微弱蒸腾，远处是绿草足球场和白色球门，四周环绕着高大茂密的香樟树。
灰色水泥看台台阶上落着树荫斑驳的碎影，旁边放着几瓶未开封的矿泉水和搭在栏杆上的蓝白校服外套。青春阳光，35mm电影质感，景深自然，真实运动场氛围，8k。
```

##### 【黄昏散场·空旷跑道】
```markdown
16:9横屏，中国青春电影剧照。傍晚六点的高中操场，落日余晖把整片红色跑道染上淡淡暖红。
空旷的绿茵场，两个单肩背包穿蓝白校服的学生背影在跑道边慢慢走，影子被夕阳拉得很长，微风吹拂衣角，宁静且充满青春心事，阿莱摄影机拍摄，8k。
```

### 场景 4：教学楼天台 (Rooftop / Secret Base)

#### 1. 核心视觉要素
* **地面与围栏**：沥青防水层地面微起伏，四周是绿色铁丝网或灰白色水泥女儿墙，带有一点风雨剥蚀的水痕。
* **环境特色**：生锈的铁门（常年虚掩或被挂锁挂住）、白色大型水箱、排风管道。
* **功能作用**：青春心事的避风港，两人午休偷吃冰棒、月考失利后宣泄委屈、避开人群的深层次交心对话。

#### 2. 标准 Prompt
```markdown
16:9横屏，中国青春电影剧照，高中教学楼空旷天台。
阴天多云或傍晚的微风吹拂，灰色水泥地坪，边缘是生锈的铁丝网和半截女儿墙。天台角落放着蓝白涂层的通风管道。
站在天台可以俯瞰整座校园的红色教学楼顶和远处城市的住宅楼。天空云层翻滚或微蓝，具有广阔孤独感与青春秘密基地的质感，35mm胶片，真实生活，8k。
```

### 场景 5：校门口香樟大道与自行车棚 (School Gate & Bike Shed)

#### 1. 核心视觉要素
* **校门与大道**：宽阔的沥青马路，两侧种满遮天蔽日的老香樟树，阳光透过树叶筛下密密麻麻的金色光斑；校门口伸缩电动门。
* **自行车棚**：蓝色铁皮波浪瓦遮雨棚，下方整整齐齐锁满黑色横梁老单车、山地车和粉色/银色弯梁轻便自行车。
* **功能作用**：放学同行、单车后座的载人与躲避、暴雨中撑伞等人的终局戏剧冲突。

#### 2. 标准 Prompt

##### 【放学单车棚·推车同行】
```markdown
16:9横屏，中国青春电影剧照，放学时分的学校老旧自行车棚。
蓝色波浪铁皮雨棚下排满了各式中学生山地车和普通自行车。傍晚的柔和斜光洒在车把反光镜上，一辆黑色横梁山地车旁挂着一个深灰色双肩包。
棚外是高大的梧桐树荫，放学人潮隐在虚化背景中，充满生活烟火气的放学瞬间，35mm胶片，真实质感，8k。
```

##### 【暴雨校门口·阶梯避雨】
```markdown
16:9横屏，中国青春电影剧照，暴雨中的学校教学楼门厅台阶。
倾盆大雨如注，密集的雨幕笼罩着整个湿漉漉的校园水泥广场，雨水在地面溅起白色水花和积水倒影。
教学楼一楼大厅的避雨台阶处，瓷砖湿滑，门外大雨倾盆，冷青色雨天光影，真实水气与雨丝质感，充满阻隔感与等待氛围，阿莱摄影机，8k。
```
