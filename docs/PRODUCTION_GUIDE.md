# 生产合成与一致性执行指南 (Production & Consistency Guide)

> 本指南用于规范在即梦 AI（Jimeng AI）、Midjourney、ComfyUI 及剪映等生产工具中，将【角色资产】与【场景资产】有机融合并防止 AI 幻觉和穿帮的通用操作法则。

---

## 一、 “积木式” Prompt 组装公式

在创作任何一个具体分镜头时，严禁随心所欲乱写提示词。必须按照以下 **五层积木结构** 严格拼装：

```text
[画幅与基础画风] + [场景定位与空间轴线] + [角色A状态与动作] + [角色B状态与动作] + [摄影器材与防穿帮约束]
```

### 组装示范：

```markdown
【第一层：画幅与风格】
16:9横屏，中国青春电影剧照，真实生活质感，严谨空间连戏。

【第二层：场景与空间】
场景为高三教室靠窗课桌（参考 SCENE_BIBLE 场景1）：画面右侧是高大的推拉窗，午后柔和自然光从右往左照；课桌堆着五三真题与草稿纸，桌角立着银色黑盖不锈钢保温杯。

【第三层：角色 A (江野)】
画面左侧（靠过道）：男主江野（183cm，清爽黑色自然短碎发绝非寸头，蓝白校服敞开露出纯黑T恤），单手撑桌俯身前倾，下颌紧绷，眼神锐利冷冽直视前方。

【第四层：角色 B (陆晚晚)】
画面右侧（靠窗台）：女主陆晚晚（162cm，高马尾配薄碎刘海，蓝白校服拉到胸口），坐在位置上微微仰头，圆杏眼带着意外与怔忡。

【第五层：摄影与画质】
35mm电影胶片质感，真实自然的皮肤纹理毛孔，阿莱摄影机拍摄，无过度美颜与塑料脸，人体结构正常无多指畸形，8k分辨率。
```

## 二、 负向提示词 (Negative Prompt) 必备标准词库

在任何支持负向提示词（反向词）的平台中，必须常驻以下约束，过滤 AI 常见畸变：

```markdown
光头, 极短寸头, 卡尺头, 脏辫, 染发, 浓妆, 烈焰红唇, 假睫毛, 欧美长相,
多余的手指, 六指, 畸形手, 肢体粘连, 手臂拉伸变形, 身体扭曲,
过度磨皮, 塑料脸, AI面具感, 3D假人, 网红锥子脸, 动漫大眼眼珠变形,
欧美校服, 西装短裙, 贵族学院风, 奢华空旷教室,
大面积泛黄过饱和滤镜, 画面撕裂, 模糊, 低分辨率, 伪影, 水印, 文字乱码
```

## 三、 即梦 AI (Jimeng AI) 垫图 / 参考图权重调优法则

在即梦中实现连戏，参考图的**权重滑块（Weight Slider）**是成败关键：

| 生成目标 | 推荐垫图母本 | 参考类型 | 推荐权重区间 | 调参说明 |
| :--- | :--- | :--- | :---: | :--- |
| **单人稳定特写** | 角色半身定妆照 | 人物特征 | `0.65 - 0.70` | 锁脸最稳，微表情依然能被 Prompt 驱动 |
| **复杂双人互动** | 双人同框母本图 | 人物 + 场景 | `0.55 - 0.60` | 权重不宜过高，给两人伸手、俯身等动作留出变形空间 |
| **新场景空镜头** | 教室空镜头底图 | 场景与风格 | `0.45 - 0.55` | 保留相同采光色调和木纹，但不限制新角度构图 |
| **图生视频 (5s)** | 满意的高精静态图 | 首帧 / 单图 | **运动幅度设为 2** | 严禁设为 4 以上，幅度 2 只动微表情和风吹发丝，最稳定 |

## 四、 剪辑时“动静结合”成本与画质平衡原则

一部 10 分钟中视频（约 120 个镜头），如果全部跑图生视频，不仅算力成本高昂，且长片容错率极低。制作应遵循 **85/15 黄金比例**：

1. **85% 常规叙事镜头（静态高精大图 + 剪映关键帧缓推）**：
   * **适用**：所有空镜头、环境交代、背影、试卷特写、大部分日常对话；
   * **操作**：剪映中打入点缩放 `100%`、出点缩放 `105%~108%`，配合知了蝉鸣、风扇、写字沙沙声等环境拟音；
   * **收益**：0 算力消耗，4K 极限清晰度，0% 穿帮变形概率。
2. **15% 灵魂情绪镜头（即梦图生视频）**：
   * **适用**：江野冷眼转头（镜头2）、长臂截胡对峙（镜头6）、暴雨中擦肩回眸、奔跑哭泣；
   * **操作**：运动幅度设为 2，时长 3~5 秒，剪辑时只取最惊艳的 2~3 秒高光；
   * **收益**：把刀刃用在刀尖上，给观众带来强烈的电影大片质感。
