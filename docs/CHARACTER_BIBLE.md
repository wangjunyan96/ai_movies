# 角色设定规格表 (Character Bible)

> **项目名称**：`ai_movies` - 校园青春系列  
> **视觉标准**：16:9 电影级写实青春剧照，自然生活化采光，35mm 胶片质感，真实皮肤毛孔与微表情，拒绝过度美颜/磨皮与塑料感。

---

## 一、 男主角：江野 (Jiang Ye)

### 1. 核心人设与外貌特征
* **年龄 / 身份**：18 岁，高三理科班学生，嘴硬心软的学霸。
* **身高 / 体态**：183cm，身材修长挺拔，清瘦但骨架舒展，有少年运动员的舒展感，习惯单肩背深灰色书包，站立时重心偶尔微斜，带有一丝散漫随性。
* **发型与五官**：
  * **发型**：**清爽黑色自然短碎发**（额前有轻微自然薄碎刘海，顶部微蓬松，两鬓修剪干净，**严禁写成光头、卡尺头或极短圆寸**）。
  * **眉眼**：剑眉星目，单眼皮（或极窄内双），眼窝深邃，眼神清冷、淡漠但聚焦时极有神采；在面对女主时偶尔闪过一丝无奈、慌乱或温柔。
  * **下颌与五官**：高挺鼻梁，下颌线清晰利落，唇色自然偏淡，下巴线条微扬时带有少年桀骜感。
* **标志性服饰与道具**：
  * **校服**：中国经典蓝白拼色宽大拉链运动校服外套。**特点：拉链永远敞开**。
  * **内搭**：纯黑色圆领短袖 T 恤（露出锁骨下方干净平整的领口）。
  * **下装**：同套深蓝色宽松运动校服长裤，搭配干净白球鞋。
  * **标志道具**：
    * 黑色晨光按动中性笔（习惯在指尖转笔）；
    * 银色不锈钢、黑色塑料旋转杯盖立式保温杯；
    * 经常在校服右侧大口袋里揣着常温纸包红豆豆奶（利乐包 250ml）。
* **招牌动作与微表情**：
  * 说话时单手插在校服口袋里，或者单手撑着桌角俯身；
  * 被戳中心思或心虚时，习惯性轻咳一声，偏头看向窗外，喉结微动，耳尖悄悄泛红；
  * 讲题时骨节分明的右手握笔，在草稿纸上干净利落划下辅助线。

## 二、 女主角：陆晚晚 (Lu Wanwan)

### 1. 核心人设与外貌特征
* **年龄 / 身份**：18 岁，高三学生，数学偏科但性格坚韧、乐观善良的元气邻家女孩。
* **身高 / 体态**：162cm，娇小匀称，站立在江野身旁刚好到江野肩膀高度（形成完美的 21cm 身高差）。
* **发型与五官**：
  * **发型**：**清爽蓬松高马尾**，配额前微微吹拂的薄空气碎刘海，耳畔有自然落下的碎发丝，发绳为简单黑色或草莓红细发圈。
  * **眉眼**：清澈圆杏眼，双眼皮自然，卧蚕明显，哭泣或受委屈时眼眶和鼻尖泛红，惹人怜惜；笑起来眉眼弯弯如月牙。
  * **面部微表情**：胶原蛋白饱满的鹅蛋脸，生气委屈时两腮会像仓鼠一样微微鼓起，嘴唇微抿。
* **标志性服饰与道具**：
  * **校服**：同款中国经典蓝白拼色运动校服外套。**特点：拉链规矩拉到胸口上方，袖口稍长，习惯性遮住半个手掌**。
  * **内搭**：浅灰或浅白色棉质圆领打底衫。
  * **标志道具**：
    * 咬着细吸管喝的 250ml 纸包常温红豆豆奶；
    * 贴满各种粉色、黄色纠错便利贴的厚笔记本与错题集；
    * 做题苦恼时手里捏着的圆规或粉色橡皮擦。
* **招牌动作与微表情**：
  * 遇到解不开的数学题，会抓狂地把整张脸埋进宽松的校服袖子里叹气；
  * 被江野怼急了会用笔尖在课桌三八线上用力划界限，鼓着脸瞪他；
  * 接过温暖的东西时会双手捧着，低头浅浅抿嘴笑。

## 四、 角色一致性（锁脸 / 防穿帮）红线规范

在任何 AI 图像/视频生成中，必须严格执行以下防穿帮规则：

| 校验维度 | 江野 (男主) 绝对规范 | 陆晚晚 (女主) 绝对规范 | 严重违规（立即废弃） |
| :--- | :--- | :--- | :--- |
| **发型** | 清爽短碎发，额前微薄碎刘海 | 蓬松高马尾，空气薄碎刘海 | 出现光头、圆寸、及肩长发、波浪卷 |
| **上衣拉链** | **必须敞开**，露出黑色圆领内搭 | **拉到胸口上方**，露出浅灰打底 | 男女主校服款式颠倒、拉链反常 |
| **身材比例** | 183cm 舒展清瘦骨架，手指修长骨节明显 | 162cm 娇小身材，手掌偏小，袖子遮半手 | 手部出现多指、短粗肥大或肌肉过于健美 |
| **妆容风格** | 纯天然素颜、生活质感皮肤 | 纯天然素颜、清透无浓妆 | 出现红唇烈焰、假睫毛、浓眼线或磨皮橡皮人 |
